اعزاز المیراث — انسٹال ہونے والی ایپ (PWA)

اس فولڈر کو کسی HTTPS ہوسٹنگ پر اپلوڈ کریں (مثلاً GitHub Pages، Netlify، Cloudflare Pages)۔
پھر موبائل کے Chrome میں لنک کھولیں اور مینو سے "Install app" / "Add to Home screen" دبائیں۔
iPhone میں Safari سے: Share ← Add to Home Screen۔
پہلی بار آن لائن کھولنے کے بعد ایپ بغیر انٹرنیٹ بھی چلتی ہے۔

Android APK چاہیے ہو تو ہوسٹ شدہ لنک pwabuilder.com میں ڈال کر APK بنائی جا سکتی ہے۔
